# Ты лидер 2026

Мобильный тренажёр: 1 153 карточки, 10 тем, 27 портретов, шесть режимов, интервальное повторение.

Сайт: https://sillqz.github.io/ty-lider-2026/

Без аккаунтов и облачной синхронизации. Прогресс хранится в localStorage этого браузера. Для переноса используйте экспорт и восстановление резервной копии в настройках. Очистка данных браузера может удалить прогресс — сохраняйте копию отдельно.

На iPhone: Safari → Поделиться → На экран «Домой». На Android: Chrome → меню → Установить приложение. После первой загрузки дождитесь в настройках сообщения о готовности материалов без интернета.

GitHub Pages публикует корень ветки main. Сборка и сервер не нужны; .nojekyll отключает обработку Jekyll. Все необходимые для тренировки файлы размещены здесь, внешних API нет. Внешние ссылки на источники открываются только по нажатию.

Материалы и атрибуция изображений: раздел «Источники и лицензии» приложения и assets/portraits/attribution.json. Формулировки исходных карточек сохранены; актуальность норм и должностей не проверялась.
